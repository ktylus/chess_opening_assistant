### About the project

This project is about creating an agent-powered LLM-based assistant which aids in learning chess openings.
currently on the chessboard. The assistant should be able to answer questions about the nature of the position, highlighting key tactical and positional ideas, topical pawn breaks, etc.
The system will be supported by relevant documents allowing for augmenting the context by precise retrieval.

The environment is controlled with `uv`. Git bash is available for bash execution.
